# Lote 5 — TID-DADOS-VIZ (P1 7.1 e 8.1–8.4) — itens

Itens para julgar (C = certo, E = errado). Gabarito e justificativas no arquivo L5_gabarito.md.

**Comando.** Acerca de dados, atributos, métricas e transformação de dados, julgue os itens a seguir.

**A5-01** — Em uma base de dados de proposições legislativas, "partido do autor" é exemplo de atributo, enquanto "número de proposições apresentadas por mês" é exemplo de métrica.

**A5-02** — A padronização das grafias "PL", "P.L." e "Projeto de Lei" em uma base de proposições é operação de limpeza de dados, e não de agregação, ainda que modifique os valores de um atributo.

**A5-03** — A transformação de dados restringe-se às operações que alteram a estrutura das tabelas, como a junção e a pivotagem, não abrangendo a filtragem de registros nem a criação de campos calculados.

**A5-04** — Dados estruturados são aqueles que não seguem esquema predefinido, como textos livres de discursos parlamentares e arquivos de áudio de sessões.

**Comando.** A respeito dos princípios de visualização de dados, julgue os itens a seguir.

**A5-05** — Na visualização de dados, é recomendável destacar a mensagem principal e eliminar elementos decorativos que não carreguem informação, de modo a reduzir o ruído visual.

**A5-06** — Em gráfico de barras, iniciar o eixo vertical em valor diferente de zero é prática recomendada, pois amplia as diferenças entre as categorias sem comprometer a integridade da leitura.

**A5-07** — Para representar categorias sem ordem natural, como as unidades da Federação, recomenda-se paleta de cores sequencial, que sugere progressão de menor para maior valor.

**Comando.** Acerca dos tipos de gráficos, julgue os itens a seguir.

**A5-08** — No histograma, a altura de cada barra é sempre proporcional à frequência da respectiva classe, independentemente de as classes terem ou não a mesma amplitude.

**A5-09** — No histograma, as barras são contíguas porque as classes são intervalos adjacentes de uma escala numérica; no gráfico de barras, que compara categorias, o espaçamento entre as barras é convenção de desenho.

**A5-10** — O gráfico de linha é o mais indicado para comparar valores entre categorias sem ordem natural, como as comissões temáticas, porque a inclinação dos segmentos evidencia a diferença entre elas.

**A5-11** — No gráfico de dispersão, mesmo quando os pontos se alinham quase perfeitamente, o padrão observado indica correlação entre as duas variáveis quantitativas, e não comprova que uma cause a outra.

**A5-12** — O box plot exibe a forma detalhada da distribuição de uma variável quantitativa, permitindo identificar bimodalidade com a mesma clareza que um histograma.

**A5-13** — No box plot, a linha no interior da caixa representa a mediana e pode situar-se fora do centro da caixa quando a distribuição é assimétrica, sem que isso indique erro de construção.

**Comando.** Acerca das ferramentas de visualização de dados, julgue os itens a seguir.

**A5-14** — O Power BI é composto pelo Power BI Desktop, aplicativo para Windows no qual os relatórios são criados; pelo serviço do Power BI, plataforma on-line para publicação e compartilhamento; e por aplicativos móveis para consumo.

> Atenção: conteúdo sujeito a mudança; será reverificado em janeiro de 2027.

**A5-15** — A ferramenta Data Studio, do Google, foi descontinuada em 2022 e substituída pelo Looker Studio, de modo que a denominação Data Studio não corresponde a produto vigente.

> Atenção: conteúdo sujeito a mudança; será reverificado em janeiro de 2027.

**A5-16** — O Tableau Public é uma plataforma gratuita para criar e compartilhar publicamente visualizações, enquanto o Tableau Server é a versão auto-hospedada da plataforma e o Tableau Cloud, a versão totalmente hospedada em nuvem.

> Atenção: conteúdo sujeito a mudança; será reverificado em janeiro de 2027.

**A5-17** — No fluxo de trabalho típico do Power BI, o relatório é criado no serviço on-line e, em seguida, publicado no Power BI Desktop para consumo pelos usuários.

> Atenção: conteúdo sujeito a mudança; será reverificado em janeiro de 2027.

**Comando.** No que se refere ao storytelling para visualização de dados, julgue os itens a seguir.

**A5-18** — O storytelling para visualização de dados combina dados, elementos visuais e narrativa para comunicar uma mensagem e conduzir o público a uma conclusão ou ação.

**A5-19** — A análise exploratória é aquela em que o analista, já conhecendo a mensagem principal, seleciona os dados que a sustentam para conduzir o público a uma conclusão.

**A5-20** — Em uma apresentação com storytelling, o uso de cor de destaque e de anotações para direcionar a atenção ao ponto-chave do gráfico contribui para a clareza da mensagem.
